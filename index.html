TOOL OVERVIEW

A clearer way to explain payroll reconciliation

Before opening the live application, visitors can understand exactly what the tool does and how the reconciliation workflow works.

Brief

The Payroll Reconciliation Checker compares an Expected Payroll file against a Processed Payroll file. It places the values side by side so payroll differences can be spotted quickly and investigated before the reconciliation is completed.

The comparison can include fields such as Gross Pay, PAYE, Employee NI, Pension, Other Deductions and Net Pay, depending on the structure of the uploaded payroll files.

The purpose is to make payroll review easier to follow, reduce manual comparison effort, and help focus attention on records that do not match.
