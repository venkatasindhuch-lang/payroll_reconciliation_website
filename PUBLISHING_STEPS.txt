OPEN LOCALLY
1. Extract the ZIP.
2. Keep all files together.
3. Double-click index.html.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository, e.g. payroll-reconciliation-website
2. Upload:
   index.html
   favicon.svg
   expected_payroll_demo.xlsx
   processed_payroll_demo.xlsx
3. Commit changes.
4. Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: main.
7. Folder: /(root).
8. Save.
